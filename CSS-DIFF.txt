───────────────────────────────────────────────────────────────────────────────
1. CONTENEDOR PRINCIPAL - .auth-shell-image
───────────────────────────────────────────────────────────────────────────────

CAMBIO:
  justify-content: flex-end   →   justify-content: center

EFECTO:
  ✓ Formulario se centra en el viewport
  ✓ Coincide con la zona blanca de la imagen
  ✓ Mejor equilibrio visual


───────────────────────────────────────────────────────────────────────────────
2. CONTENEDOR DEL FORMULARIO - .auth-overlay-form
───────────────────────────────────────────────────────────────────────────────

CAMBIOS:

  max-width: 360px  →  max-width: 450px
  ✓ +90px más ancho (+25%)
  ✓ De ~20% a ~50% del espacio disponible

  width: 100%  →  width: calc(100% - 60px)
  ✓ Respeta los márgenes del viewport
  ✓ No llena completamente en escritorio

  padding: 40px 60px  →  padding: 40px 40px
  ✓ Padding simétrico (igual arriba/abajo, igual izquierda/derecha)
  ✓ Mejor equilibrio visual

  margin: 0 30px 0 auto  →  margin: 0
  ✓ Sin margen especial
  ✓ Flexbox lo centra automáticamente


───────────────────────────────────────────────────────────────────────────────
